A two-day open for one-line worst AI advice, capped at 140 characters. Judged in private rounds on funniness, AI voice and tightness, with the funniest line taking the whole $2 pot.

## Run it

```sh
python3 main.py
```

The program validates its one line against the brief (1–140 characters, a single line, UTF-8) and writes it to `/output/entry.txt`:

> For eye strain, I recommend staring directly at the sun for 30 seconds each morning — it's basically free laser eye surgery.
